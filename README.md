# Cancun Concierge DMC — Main Website

Bilingual (English/Spanish) high-performance marketing and booking website for Cancun Concierge DMC, a boutique Destination Management Company in Cancún and the Riviera Maya.

## Tech Stack

- **Astro 5** — static site generation for speed and SEO
- **React 19** — interactive islands (header, team menu, gallery, booking form)
- **Tailwind CSS v4** — responsive, modern styling
- **Stripe** — checkout via external payment proxy
- **Swiper / AOS** — carousels and scroll animations

## Features

- Bilingual content (English at `/`, Spanish at `/es`) with custom i18n system
- Home, About (team), Services, Gallery and Transportation pages
- Live transportation booking form with real-time pricing and Stripe checkout
- Advanced SEO: localized meta, hreflang, Open Graph, JSON-LD, sitemap
- Bilingual privacy policy rendered from MDX
- Floating WhatsApp button and interactive testimonials

## Setup

```sh
pnpm install
pnpm dev
pnpm build
```

# Cancun Concierge DMC — Sitio web principal

Sitio web bilingüe (inglés/español) de alto rendimiento para marketing y reservas de Cancun Concierge DMC, una Destination Management Company boutique en Cancún y la Riviera Maya.

## Tech Stack

- **Astro 5** — generación de sitios estáticos para velocidad y SEO
- **React 19** — islas interactivas (header, equipo, galería, formulario de reservas)
- **Tailwind CSS v4** — estilos modernos y responsivos
- **Stripe** — checkout mediante proxy de pagos externo
- **Swiper / AOS** — carruseles y animaciones de scroll

## Features

- Contenido bilingüe (inglés en `/`, español en `/es`) con sistema i18n propio
- Páginas de inicio, Nosotros (equipo), Servicios, Galería y Transportación
- Formulario de reserva de transporte en vivo con precios dinámicos y Stripe
- SEO avanzado: meta localizadas, hreflang, Open Graph, JSON-LD, sitemap
- Política de privacidad bilingüe renderizada desde MDX
- Botón flotante de WhatsApp y testimonios interactivos
